# ❌⭕ Крестики-нолики против бота

Небольшая браузерная игра на **HTML, CSS и JavaScript**. Никаких фреймворков, зависимостей или сборки — открой `index.html` в браузере.

## Возможности

- Игровое поле 3×3 на CSS Grid.
- Игрок ставит X, бот ставит O в **случайную свободную** клетку.
- Нельзя занять уже заполненную клетку или ходить, пока думает бот.
- Проверка победы (8 комбинаций) и ничьей.
- Подсветка выигрышных клеток, счётчик побед / поражений / ничьих.
- «Новая игра» сбрасывает поле, но сохраняет счёт до обновления страницы.
- Адаптивная вёрстка для телефона и компьютера.

## Запуск

1. Скачай репозиторий (`git clone https://github.com/ibrodevs/Tic-tac-toe.git`).
2. Открой файл `index.html` в браузере. Всё работает без установки Node.js.

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | Девять кнопок-клеток, счёт и кнопка новой игры |
| `style.css` | Сетка 3×3, цвета, анимации, адаптивность |
| `script.js` | Обработка клика, ход бота, проверка победы, перезапуск |

## Объяснение JavaScript для защиты

1. `board = Array(9).fill("")` — массив из девяти пустых клеток. Индексы: `0,1,2 / 3,4,5 / 6,7,8`.
2. `addEventListener("click", playerMove)` — клик вызывает функцию хода игрока.
3. `makeMove(index, "X")` — ставит крестик в массив и на экран.
4. `winningLines` — все восемь троек индексов, которые дают победу. `findWin` ищет совпадающую тройку.
5. `checkGame` проверяет: есть победитель? заполнены все клетки? Если да, выводит результат.
6. Если игра не окончена, бот ждёт 450 мс. `filter` выбирает свободные клетки, `Math.random()` выбирает одну из них, `makeMove(..., "O")` ставит нолик.
7. `newGame` очищает поле и отменяет отложенный ход бота через `clearTimeout`.

> Бот специально **случайный**, а не «умный»: это требование практической работы.
